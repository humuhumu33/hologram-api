# content-address any bytes
sha256sum file.bin          # → sha256:<hex>
b3sum file.bin              # → blake3:<hex>   (b3sum is optional)

# verify: the hex must match the address exactly
echo "<hex>  file.bin" | sha256sum -c -
import hashlib

def address(path):
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(8 << 20), b""):
            h.update(chunk)
    return "sha256:" + h.hexdigest()

assert address("file.bin") == "sha256:<hex>", "not the bytes that were addressed"

How it holds up

No trusted serverHashing runs where the bytes are. Model documents are checked against their own manifest address, and every file carries its SHA-256.
Free at any scaleStatic files on GitHub Pages and jsDelivr. Each user's CPU does its own hashing, so more traffic costs nothing extra.
Public historyThe model index is a Git repository refreshed daily. A silent change to a published address would show in the history.
Plain standardssha256: for interoperability (RFC 9530, OCI, Hugging Face LFS), blake3: for speed. Plain HTTPS URLs.
